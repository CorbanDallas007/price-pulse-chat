Выступи в роли Senior Full-Stack & Data Extraction разработчика. Создай веб-приложение `stealth-price-chat` без использования LLM/ИИ для поиска топ-5 самых дешевых предложений по всем маркетплейсам и интернет-магазинам (Ozon, Wildberries, Яндекс Маркет, DNS, Ситилинк и др.) в формате современного чата.

Архитектура должна состоять из модульного бэкенда и чистого фронтенда:

1. Frontend (`index.html` — единый файл со встроенными CSS и JS):
- Современный интерфейс чата (тёмная тема, плавная анимация, автопрокрутка).
- Поле ввода внизу экрана, отправка по Enter, быстрые теги-примеры («PS5 Slim», «RTX 5060 Ti 16GB», «iPhone 15»).
- Отображение прогресса поиска по площадкам («Опрашиваем маркетплейсы и агрегаторы...»).
- Вывод ответа в виде 5 карточек лучших предложений, отсортированных строго по возрастанию цены:
    * Бейдж с названием маркетплейса/магазина (с цветовой кодировкой под каждый бренд)
    * Название товара
    * Актуальная цена крупным шрифтом (например: 52 490 ₽)
    * Кнопка «Купить» (открывает ссылку на товар в новой вкладке)
- Кнопка очистки истории чата.

2. Backend (`server.py` на Python + FastAPI) с мульти-источниковой архитектурой и защитой от банов:
- Эндпоинт `POST /api/search`, принимающий `{"query": "..."}`.
- **Паттерн «Адаптеры источников» (BaseScraper):**
    * Реализуй параллельный асинхронный сбор данных (`asyncio.gather` с `return_exceptions=True`, чтобы падение одного сайта не ломало весь поиск) из нескольких источников:
        1. Адаптер товарного агрегатора (например, поисковая товарная выдача / Price.ru), который сразу возвращает предложения с разных маркетплейсов.
        2. Адаптер прямого JSON-поиска (на примере открытого поискового API маркетплейса с параметрами региона).
        3. Поддержка опционального подключения SERP/Scraping API (через переменную окружения `SERP_API_KEY`) для гарантированного обхода любых капч.
- **Система Anti-Ban и Anti-Bot (критично):**
    * Использовать `curl_cffi.requests.AsyncSession(impersonate="chrome124")` для полного совпадения TLS-отпечатка (JA3/JA4) и HTTP/2 с настоящим браузером Chrome.
    * Для каждого источника хранить отдельную сессию с предварительным «прогревом» cookies (запрос к главной странице при старте или раз в 30 минут).
    * Добавить `asyncio.Semaphore` (лимит одновременных запросов на один домен), случайные задержки (`random.uniform(0.7, 1.8)`) и умный Retry с экспоненциальной паузой при получении 403/429.
    * Встроить ротатор прокси из переменной `PROXY_LIST` (поддержка HTTP и SOCKS5) с автоматическим исключением «забаненного» прокси на 10 минут.
    * In-Memory TTL кэш на 15 минут по нормализованному запросу (в нижнем регистре без лишних пробелов).
- **Умная дедупликация и очистка (без ИИ):**
    * Объединить результаты со всех источников, удалить дубликаты ссылок.
    * Отфильтровать аксессуары и запчасти по словарю стоп-слов (`чехол`, `кабель`, `стекло`, `наклейка`, `коробка`, `подставка`, `геймпад`, `джойстик`, `ремонт`, `уценка`).
    * Отсечь выбросы с подозрительно низкой ценой (дешевле 30% от медианной цены всех найденных товаров) и вернуть ровно 5 самых дешевых валидных предложений.

Требования к ответу:
- Выдай полный, рабочий, структурированный код (`server.py` и `index.html`) без заглушек и сокращений.
- Добавь подробную инструкцию: как установить зависимости, как при необходимости прописать прокси или ключ SERP API в `.env`, и как легко добавить новый магазин в виде отдельного класса-адаптера.
